
# NEXUS PS2 ANDROID

A dedicated Android compatibility project for Ultraman Nexus (PlayStation 2).

## Project Goal
Run the original Ultraman Nexus PS2 game on Android without relying on an existing PS2 emulator application.

## Target Device
- Android ARM64
- Snapdragon 685
- Adreno 610
- 6GB RAM

## Development Environment
- GitHub
- GitHub Actions
- Android NDK
- C++
- Kotlin

## Development Roadmap
1. Analyze PS2 disc image (BIN/CUE).
2. Identify SYSTEM.CNF and game ELF.
3. Analyze PS2 executable architecture.
4. Develop PS2 compatibility and translation components.
5. Implement graphics and audio support.
6. Implement Android touchscreen controls.
7. Build and test APK.

## Important
This project is dedicated to Ultraman Nexus PS2.
No existing PS2 emulator application is used as the runtime.

Development status: Initial setup.
